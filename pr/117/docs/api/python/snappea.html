snappea

Check P specs against events emitted by your code during its tests.

Install the pysnappea distribution and import its API from snappea.

Application code calls emit(). Tests are checked either by the pytest plugin (every test, configured under [tool.snappea] in pyproject.toml) or explicitly with check_spec(), expect_violation() and check_events(). In production, set_sink() sends the same events to a file, stdout or a callback for snappea observe.

 49class check_spec:
 50    """Checks the events emitted inside the block against P specs::
 51
 52        with check_spec("MutualExclusion") as rec:
 53            server.acquire("c1")
 54            server.acquire("c2")
 55
 56    The block observes events sent with :func:`emit`; it does not intercept ordinary
 57    method calls or run P drivers.
 58    No spec names means every spec in the spec files. Raises :class:`SpecViolation`
 59    (an ``AssertionError``) at the end of the block, so the test fails on this line,
 60    or :class:`SetupError` if the check cannot run. Options are those of
 61    :class:`Recorder`: ``check_hot=True`` also fails if a spec is left in a hot state;
 62    ``strict`` (default: true when specs are named) requires relevant events for every
 63    selected spec. When this named-spec default applies, missing relevant events currently
 64    warn; set ``strict=True`` explicitly to fail on them. ``unknown_events`` ("error" by
 65    default) handles undeclared names.
 66    """
 67
 68    def __init__(
 69        self,
 70        *specs: str,
 71        spec_files: Optional[Sequence[str]] = None,
 72        check_hot: Optional[bool] = None,
 73        strict: Optional[bool] = None,
 74        unknown_events: Optional[str] = None,
 75        timeout: Optional[float] = None,
 76        artifacts: Optional[str] = None,
 77        liveness: Optional[bool] = None,
 78    ):
 79        self.recorder = Recorder(
 80            specs,
 81            spec_files=spec_files,
 82            check_hot=check_hot_arg(check_hot, liveness),
 83            strict=strict,
 84            unknown_events=unknown_events,
 85            timeout=timeout,
 86            artifacts=artifacts,
 87        )
 88
 89    def __enter__(self) -> Recorder:
 90        return self.recorder.start()
 91
 92    def __exit__(self, exc_type: Any, exc: Any, tb: Any) -> None:
 93        __tracebackhide__ = True
 94        self.recorder.stop()
 95        if exc_type is None:
 96            self.recorder.check()
 97        else:
 98            self.recorder._cleanup_owned()

101class expect_violation:
102    """The block must break `spec`, like ``pytest.raises``::
103
104        with expect_violation("MutualExclusion", match="c2 entered"):
105            server.acquire("c1")
106            server.acquire("c2")
107
108    The block passes if a :class:`SpecViolation` of `spec` is raised inside it (by
109    :func:`check_events` or a nested :func:`check_spec`) or if the events emitted inside
110    it break the spec. ``match`` is a regular expression searched for in the spec's
111    message. Enclosing checks, such as the pytest plugin's, ignore `spec` for the rest of
112    the test. The violation is available as ``.violation`` afterwards.
113    """
114
115    def __init__(
116        self,
117        spec: str,
118        match: Optional[str] = None,
119        *,
120        spec_files: Optional[Sequence[str]] = None,
121        check_hot: Optional[bool] = None,
122        unknown_events: Optional[str] = None,
123        timeout: Optional[float] = None,
124        artifacts: Optional[str] = None,
125        liveness: Optional[bool] = None,
126    ):
127        self.spec = spec
128        self.match = match
129        self.recorder = Recorder(
130            [spec],
131            spec_files=spec_files,
132            check_hot=check_hot_arg(check_hot, liveness),
133            strict=False,  # the spec must break; whether it saw events is beside the point
134            unknown_events=unknown_events,
135            timeout=timeout,
136            artifacts=artifacts,
137        )
138        self.violation: Optional[SpecViolation] = None
139
140    def __enter__(self) -> "expect_violation":
141        from . import _emit
142
143        for outer in _emit._recorders:
144            outer.ignored.add(self.spec)
145        self.recorder.start()
146        return self
147
148    def __exit__(self, exc_type: Any, exc: Any, tb: Any) -> bool:
149        __tracebackhide__ = True
150        self.recorder.stop()
151        found: Optional[SpecViolation] = None
152        if exc_type is not None:
153            if isinstance(exc, SpecViolation):
154                found = next((v for v in [exc, *exc.others] if v.spec == self.spec), None)
155            if found is None:
156                self.recorder._cleanup_owned()
157                return False  # some other failure: let it through
158        else:
159            found = next((v for v in self.recorder.violations() if v.spec == self.spec), None)
160        if found is None:
161            n = len(self.recorder.events)
162            raise AssertionError(f"expected P spec {self.spec} to be broken, but it held over {n} event(s)")
163        if self.match is not None and not re.search(self.match, found.message):
164            raise AssertionError(
165                f"P spec {self.spec} was broken, but its message {found.message!r} "
166                f"does not match {self.match!r}"
167            )
168        self.violation = found
169        return True

184
185        check_events(captured_events, "MutualExclusion")
186
187    Events should normally come from observed implementation behavior, with payloads
188    describing actual results and state. In Python tests, prefer application calls
189    to :func:`emit`, captured automatically by the pytest plugin or inside
190    :func:`check_spec`::
191
192        with check_spec("MutualExclusion"):
193            server.acquire("c1")

204    observation. Keep observation-only monitors outside a model test project, or use a
205    reasoned ``unselected-spec`` lint suppression for intentional observation-only use.

207    collapsing distinct results can hide violations. These events do not reach any
208    enclosing check. Options are those of :func:`check_spec`.
209    """

216        unknown_events=unknown_events,
217        timeout=timeout,
218        artifacts=artifacts,
219    )
220    rec._events.extend(events_from_dicts(events))
221    rec.check()

314def set_sink(target: SinkTarget) -> Optional[Sink]:
315    """Sends events to `target` when no test is recording, as the JSON lines
316    ``snappea observe`` reads. `target` is a file path (appended to), ``"-"`` or a text
317    stream such as ``sys.stdout``, a callable taking one line (no newline), or ``None``
318    to turn the sink off. Returns the new :class:`Sink` (``None`` for off).
319
320    Inside a recording test, or in a process a test started, events go to the test
321    instead. ``emit`` never raises or blocks because of the sink.
322    """
323    global _sink
324    old, _sink = _sink, None
325    if old is not None:
326        old.close()
327    if target is not None:
328        _sink = Sink(target)
329    return _sink

class Sink:

Where emit() writes events outside tests. Made by set_sink().

Lines are queued and written by a background thread, so emit never blocks or raises. When the queue is full or a write fails, the event is dropped and counted in dropped.

def flush(self, timeout: float = 5.0) -> bool: 
290    def flush(self, timeout: float = 5.0) -> bool:
291        """Waits up to `timeout` seconds for queued events to be written. Returns
292        whether they were."""
293        deadline = time.monotonic() + timeout
294        while self._queue.unfinished_tasks and self._pid == os.getpid():
295            if time.monotonic() >= deadline:
296                return False
297            time.sleep(0.005)
298        return True

def close(self, timeout: float = 5.0) -> None: 
300    def close(self, timeout: float = 5.0) -> None:
301        """Writes what is queued and stops the writer. Later events are ignored."""
302        with self._lock:
303            if self._closed:
304                return
305            self._closed = True
306            if self._pid == os.getpid():
307                try:
308                    self._queue.put_nowait(None)
309                except queue.Full:
310                    pass
311        self.flush(timeout)

class Recorder:

Collects the events emitted while it is active and checks them against P specs.

Every option left as None comes from [tool.snappea] in the nearest pyproject.toml (and the environment variables that override it), else its default:

  • specs: the specs to check; none means every spec in the spec files (except exclude).
  • spec_files: the P files: paths, globs, or folders meaning every .p in them. Relative to the working directory here; to the pyproject.toml in config.
  • strict: require a relevant event for every selected spec. Default: true when specs are named, false for every spec. When this named-spec default applies, missing relevant events currently warn; set strict=True explicitly to fail.
  • check_hot: also fail on a spec left in a hot state. Default: false.
  • unknown_events: an event name no P file declares is an "error" (default), a "warn"\ ing, or "ignore"\ d.
  • timeout: seconds the checker may run. Default: 30.
  • artifacts: folder to keep a failed check's events and output in. Default: a temp folder. SNAPPEA_ARTIFACTS overrides [tool.snappea].

After a check, report holds snappea's JSON result, with each spec's monitor coverage.

class SetupError(builtins.Exception):

The check could not run, or its input was bad: anything but a broken spec.

kind says why, for assertions without matching message text:

  • binary_missing: no snappea binary
  • config: bad options or [tool.snappea], missing spec files, P compile errors, an unknown spec name
  • parser: an event line or payload snappea cannot read (including truncated lines)
  • validation: strict found a selected spec with no relevant event
  • unknown_event: an event name no P file declares, under unknown_events="error"
  • out_of_order: live input out of order
  • timeout: the checker ran longer than timeout

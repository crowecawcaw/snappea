# Single-file skill examples trial

See [results](RESULTS.md) and [verified records](results.json). See [protocol](PROTOCOL.md) for frozen comparisons. `experiment.py start` provisions twelve isolated trials after `runs/snapshots.json` maps `multi` and `single` to verified content-addressed skill snapshots. Delegate each recorded prompt to its metadata-selected fresh agent. Save final replies as `agent-final.txt`, then `complete.py ID` freezes and grades while retaining Docker lifecycle events and console output even on resource failure. Once all finish, `analyze.py supplement` and `analyze.py summarize` verify inputs and generate results. Task harnesses and archived test cases are reused; supplemental declaration-assembly repairs are described in the protocol, preserving original grades. Raw artifacts live under existing task `runs/` and are omitted from Git.

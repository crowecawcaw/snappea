## Recurrent grammar, help, lint, and feedback friction

These are descriptions of recorded commands/results, not new tool experiments. All four read `snappea --help` and `check --help`; all also read `tests --help` somewhere. The shared help explains CLI options, coverage, mutation, driver facts and replay; it supplies no minimal valid P module/test/monitor declaration. The repeated syntax repairs occur despite those CLI reads.

1. **Test/module declaration discovery recurs in all four.** A01/T:8 `testcase AtomicCommitPoint ...` is rejected, then T:9-12 cycles through missing colon/empty-brace/create forms. T:14 reports only “the sources declare no test case,” with no example repair. T:16 `test ...: AtomicPublish;` gets “could not find module 'AtomicPublish'”; T:17-19 tries `module Check { }`, empty module membership, then module=machine, before T:20 succeeds with `module Check = { AtomicPublish };`. B01/T:8-16 repeats colon/empty body/semicolon/module-vs-machine/nested declaration errors, succeeding T:17. A02/T:7-16 and T:21 repeat the same issues. B02/T:5,8-14,16-18 does so too. Typical generic syntax help is “look for a missing ';', ')' or '}', or a misspelled keyword, here or on the line before”; useful caret/expected-token information is present, but no valid end-to-end test/module example is given.
2. **A concrete misleading suggestion loop:** A02/T:10 runs a test referring to `... assert Safety in Counter;` and gets “could not find module 'Counter'” plus “did you mean 'tcCounter'? Otherwise declare the module before using it.” T:11 follows that spelling suggestion and gets “could not find module 'tcCounter'” plus “did you mean 'Counter'?” Both are not declared modules; T:19 finally declares `module Model = { Counter };`. The feedback supplied insufficient next steps to distinguish a module value from a machine or test identifier.

B02/T:17 sees the same “could not find interface 'Safe'” for spec in module membership; T:18 removes it successfully. This is a recurring actionable-diagnostic gap, not simply a missing semicolon.

The four-run sample and common primary20 ceiling do not justify a causal or numerical quality ranking.
